# Sample credits

All samples here were synthesised for this repository: no recordings, no
sample libraries, no breaks taken from records. The breaks are programmed
patterns played on a synthesised kit. MIT, like the rest of the repo
(`LICENSE`).

| file | what | rate | frames | loop | root |
|---|---|---|---|---|---|
| `break_a.wav` | funky break, 1 bar, a 16th every 2048 frames (170 BPM at this rate) | 23211 Hz | 32768 | -- | -- |
| `break_b.wav` | tighter break with tambourine, 1 bar | 23211 Hz | 32768 | -- | -- |
| `reese.wav` | three detuned saws | 11025 Hz | 16182 | whole | C2 |
| `pad.wav` | open-fifth chord, detuned saws | 8820 Hz | 18698 | 5468 + 13230 | C3 |
| `stab.wav` | minor-seventh stab | 16000 Hz | 6720 | -- | C4 |
| `crash.wav` | crash cymbal | 16000 Hz | 16800 | -- | -- |
| `hoover.wav` | hoover | 11025 Hz | 12898 | 4630 + 8268 | C3 |

Used by `jungle_ride` (break A, reese, pad, stab, crash), `jungle_race`
(break B, reese, hoover, stab, crash) and `jungle_menu` (break A, pad, crash).
